## 📊 Overview

An interactive sales analytics dashboard built with HTML/CSS/JavaScript and backed by real Excel data. Designed as a freelance portfolio deliverable demonstrating data visualization and reporting skills.

---

## 🛠️ Features

- Interactive charts and KPI cards
- Revenue, units sold, and trend analysis
- Clean, client-ready visual design
- Fully browser-based — no server required
